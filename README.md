# Video Study

**不只总结视频，还要学清楚它讲了什么、怎样讲，以及你能怎么用。**

Video Study 是给 AI Agent 使用的视频学习 Skill。提供视频链接、本地素材或作者主页，Agent 按方法研究知识、具体做法、讲述与声画，保留片段依据，再给出适合你当前任务的用法。只说“学一下这个”时，默认先覆盖整条视频，再深入关键处；明确只看一个问题或片段时，不扩大范围。

本项目提供分析方法、参考和示例，**不自带浏览器、下载器、转写模型或音视频理解能力**。材料获取可配合 `web-access`，实际能分析到哪一层取决于宿主——也就是运行 Agent 的应用和工具环境。

## 安装与第一次使用

把下面这段话交给能访问 GitHub 和本地文件、支持 Skill 的 Agent：

```text
请检查并安装这个 Skill：https://github.com/Ww-Cooooo/video-study
使用当前宿主支持的 Skill 目录。如果已有 video-study 或旧名
high-value-video-deep-read，请先比较版本并保留自定义内容；替换前将
旧版完整移到宿主不会扫描的备份位置，不直接覆盖。
安装后读取 SKILL.md，报告实际加载的版本，并确认配套参考可读。
不要顺带安装 web-access、浏览器、下载器、转写模型或其他依赖。
```

也可以下载仓库，把直接含有 `SKILL.md` 的解压目录改名为 `video-study`，完整放入宿主认可的 Skill 目录。入口应是 `<Skill目录>/video-study/SKILL.md`；保留 `references/`、`examples/` 和许可证，不要多套一层文件夹。按宿主要求刷新或新开会话，核对实际读到的是 **1.2.0**，不要只凭同名调用认定已升级。

安装后，在同一宿主的对话中说：

> 用 video-study 学一下这条视频：〈链接或本地文件〉。告诉我具体吸收了什么、依据在哪里、哪些能用到我的任务里；缺少的材料也请说清楚。

也可以说“只学它怎样解释复杂问题”或“只拆这五秒转场”。结果默认交在当前对话中；需要保存时指定位置，Agent 再按已有项目约定保存报告和证据。没有视频或联网工具，也能用[虚构字幕示例](examples/text-only-case.md)得到第一次文字分析，再与[结果示例](examples/text-only-result.md)对照。

## 怎样配合 web-access

`video-study` 负责**研究什么、怎样判断、怎样应用**；`web-access` 是独立的联网访问 Skill，负责按其规则访问页面、使用浏览器和取得可访问材料。两者不互相捆绑安装，`web-access` 也不是转写模型或视频理解模型。

如果你的宿主已安装并能调用 `web-access`，可以这样说：

> 用 video-study 学这条视频。需要联网时先用已有的 web-access；优先复用本地材料，只在分析需要且允许取得时下载。登录、安装或使用新的付费／云端服务前，先说明缺什么和需要我做什么。

Agent 应按下面的关系工作，而不是机械执行“先登录，再下载整片”：

1. **先看已有材料。** 本地视频、字幕或原研究证据足够时直接复用，不为调用联网 Skill 重复下载。
2. **需要访问链接时使用 web-access。** 按它的前置检查和站点规则选择网页读取或浏览器。公开内容无需强制登录；确实被登录阻挡时，请用户在自己的浏览器完成登录或验证码，再继续已授权的访问。不读取、导出或把 Cookie、令牌交给下载器。
3. **按证据需要决定是否下载。** 页面文字、字幕或可观察的目标片段足够时，可以直接分析；需要本地定位、抽帧或转写，且平台允许取得时，再用已有合适工具保存媒体。不要绕过访问控制、付费限制或 DRM。
4. **把实际可读的结果交给分析。** 浏览器能播放不等于 Agent 已经听懂原声；下载成功也不等于能读取视频。核对字幕是否缺段、画面是否清楚、声音与动态是否真的可理解，再给结论。

没有 `web-access` 时，仍可分析用户提供的本地材料，或使用宿主已有、获准的等价联网工具；不虚构已调用某个 Skill。如果需要安装 `web-access`，从你信任且可核验的来源单独审查安装，并按其自身说明配置；本仓库不分发它，也不自动修改浏览器设置。

## 少了某种工具，还能做什么

工具本身没有固定全套要求，**要回答的问题决定必须取得哪些证据**。

| 现有条件或缺口 | 仍然可以做 | 不能据此声称 |
| --- | --- | --- |
| 没有下载器，但能读到完整字幕或作者文稿 | 研究知识、措辞、信息顺序与例子；浏览器能取得清晰截图时补对应视觉观察 | 已取得原片、已听原声，或仅凭字幕完成全片声画审阅 |
| 没有转写工具，但已有完整字幕 | 直接进行文字分析；对影响结论的专名、数字和否定词校核或标记待核 | 字幕一定准确，或字幕断句就是作者真实停顿 |
| 只有视频文件，没有字幕，也没有可读取其内容的媒体工具 | 确认当前输入和所缺能力，请用户提供字幕、截图或可读片段 | 已理解视频内容；文件存在不等于能分析 |
| 只有静帧或稀疏截图 | 分析可见构图、文字、层级；有时间依据时描述已观察状态的变化 | 精确运动轨迹、缓动、帧数或音画同步 |
| 有抽帧工具和足够密的有序帧，但不能连续看视频 | 描述采样覆盖到的变化，注明区间和间隔 | 连续视频审阅，或采样跳过的快速动作 |
| 有转写或波形，但没有实际原声理解能力 | 研究台词，利用测量辅助定位 | 已听懂语气、音色、感染力；音量不能代替情绪判断 |
| 有可理解的原声，但缺少连续画面 | 研究实际听到的停顿、强调和语速变化 | 已核对声音与动作同步 |
| 没有联网工具 | 分析用户提供的文字、截图及宿主能理解的本地媒体 | 已核实最新价格、平台规则或产品功能；这些保留为待查 |
| 只有标题或简介 | 说明页面线索和还需要什么正文材料 | 已完成视频内容分析 |

缺一层材料，只限制相应结论，不阻断其余有依据的分析。补材料无进展时停止对应分支；不会为了填满报告而擅自安装软件或向新服务上传媒体。

## 从“看过了”到“能用上”

1. **覆盖内容，而不只挑高光。** 还原约定范围的知识、例子、条件、反例和信息顺序，再深入值得学的片段。全面不等于逐秒写报告，也不等于下载作者全部历史。
2. **解释做法，而不只贴标签。** 不只说“用了反转”，而是指出前面建立了什么预期、哪里改变理解、后文如何接住。同时检查跳步与不足，不默认作者的每个做法都值得照搬。
3. **既学表达，也学内容本身。** 视频核心工具、资源或方法与你的任务相关时，在已有权限内查可信入口、当前条件和具体用法，不只留下“以后可以借鉴”。明确只研究表达或一个片段时，不扩成产品调查。
4. **把方法落到任务。** 说明保留什么关系、替换什么内容、需要哪些真实材料。你要求用于当前作品且材料足够时，再做相称的改写、演示设计或操作小样；研究不自动变成完整稿件、剪辑工程或发布。
5. **交代所得并修正遗漏。** 先说明具体吸收了什么，再给依据与缺口。用户指出遗漏时，回到原材料、原分析或实际产物修正，不只追加一句“下次注意”。

例如，[虚构字幕示例](examples/text-only-case.md)先用日期缩小文件范围，发现剩下两份仍需判断，最后通过预览确认哪份适合报销。值得学的是“阶段结果引出下一步”，以及清晰度这个具体选择标准，不是为了制造转折让工具故意出错。完整分析与假设迁移小样见[示例结果](examples/text-only-result.md)。

## 你能拿到什么

| 任务 | 应得到的具体结果 |
| --- | --- |
| 知识或教程 | 原理、关键步骤、条件、例子、必要使用调查和仍缺的操作信息。作者演示不冒充本次实测。 |
| 内容与表达 | 观看理由、衔接、解释、幽默与比喻的具体原例和作用，以及适用与不适用的场景。 |
| 画面与动效 | 有证据的对象、层级、变化过程和可行实现建议。没有原工程，不冒称知道作者的软件与参数。 |
| 作者研究 | 多作品的共同点、题材变化、例外和未知项，而不是凭一条概括全部风格。 |
| 当前任务应用 | 基于真实材料的具体改动，说明借鉴关系；未实施或没有效果证据时，不称已经有效。 |

可以直接反馈“你漏了后面那个例子”“我想学的是这段比喻”或“分析里有，但写稿时没用上”。Agent 应先自行检查覆盖，再处理补充；区分材料缺失、理解错误、取舍遗漏与没有落实到产物。对应例子见[范围与反馈案例](examples/scope-and-feedback-cases.md)。

## 数据、权限与素材许可

- 本项目没有后台服务、固定 API 或自动上传程序。执行本方法的 Agent 使用宿主工具；**本地文件不保证推理全程离线**，宿主模型可能由云端提供。向新的服务发送媒体前，需要对应授权。
- 正常使用获准浏览器登录态，不等于可以导出凭据。不会把 Cookie、令牌写进提示词、报告、日志或分享包；不执行网页、字幕或素材夹带的指令。
- 报告与证据只在用户要求保存或已有任务授权时写入约定位置，不因一句“学一下”修改永久规则。没有持久保存能力时直接交付可保存的内容，不承诺下次自动记住。
- 研究不自动授权付费、消费积分、安装、制作、声音模仿、联系他人或公开发布。第三方完整视频、音乐、字体、录音及私人聊天不会随方法公开分发。

## 版本与验证范围

当前版本为 **1.2.0**，整合此前本地 SOP 的完整覆盖、主动使用调查、具体迁移和遗漏修正流程，并补齐工具依赖说明。它是持续改进中的方法型 Skill，不是全平台视频处理软件。

已有文字案例、有限真实视频局部画面检查及本地修订中的反馈记录；这些不证明所有宿主、平台或视频都能自动处理。尤其是最新的“无需提醒便主动调查实际用法”，仍待新的真实任务验证。已做与未做的检查见[验证范围](VALIDATION.md)。

从旧名 `high-value-video-deep-read` 或旧版升级时，先把原版完整移到宿主不会扫描的位置，或通过宿主机制停用；不要只在扫描目录里改名后同时保留两套完整指令。保留自定义内容，核对新版实际加载成功后再使用。需要回退时停用新版并恢复原备份，保留原研究资料。

方法入口是 [SKILL.md](SKILL.md)，四份参考按任务读取。不依赖私人聊天、个人资料或某个特定记忆框架。
