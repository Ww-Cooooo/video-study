# 高价值视频深读

**从一条视频里，学到下一次真正用得上的东西。**

把视频链接、作者主页或本地素材交给 Agent，用这份 Skill 拆解内容、说话方式和画面做法。分析会指向具体片段：视频教了什么、作者怎样把话讲清、动效承担什么作用，以及你可以怎样借鉴。

它是一套分析指引，需要由你的 Agent 执行；不自带下载器、语音识别模型或剪辑软件。能分析到哪一层，取决于 Agent 实际拿到了哪些文字、声音和画面。

## 开始使用

下载本仓库，将直接包含 `SKILL.md` 的解压目录改名为 `high-value-video-deep-read`，放到你所用 Agent 支持的 Skill 目录中，保留 `references/` 等配套文件。最终入口应是 `<Skill目录>/high-value-video-deep-read/SKILL.md`，不要额外套一层文件夹。不同宿主的目录不同，可以把下面这段话交给能访问文件的 Agent：

> 请从 https://github.com/Ww-Cooooo/high-value-video-deep-read 安装这个 Skill。先确认当前宿主的 Skill 目录；若已有同名版本，保留原版并说明差异，不直接覆盖。安装后读取 SKILL.md，告诉我你实际能处理文字、声音和视频中的哪些材料，不要顺带安装模型或下载器。

安装后新开或刷新会话，让 Agent 明确调用 `high-value-video-deep-read`。第一次可以这样用：

> 用 high-value-video-deep-read 分析这条视频：〈你的链接〉。我想学它怎样讲清一个工具，以及画面怎样配合。请指出具体片段，给出适合我下一条视频尝试的做法。

没有可访问的视频也能先试：[文字示例](examples/text-only-case.md)可直接交给 Agent，[结果示例](examples/text-only-result.md)展示了一份分析可以具体到什么程度。结果默认在当前对话里；需要保存时指定项目或文件夹，通常用 Markdown 报告并链接对应证据，也可以要求其他格式。

## 可以怎样用

| 你想解决的问题 | 分析重点 |
|---|---|
| 教程看完了，怎么把方法用起来？ | 提炼原理、操作条件、关键步骤与未验证主张。 |
| 这条视频为什么讲得顺？ | 看点、前提、证据、转折和结尾怎样连接。 |
| 想学作者的表达，但不想只抄口头禅 | 分开研究语言组织和真实原声中的停顿、强调、节奏。 |
| 想知道一个动效怎么做 | 核对过程、图层、时序与内容作用，提出可行做法，区分观察和推断。 |
| 想研究一个作者的风格 | 比较有差异的多条作品，分清常用方法、题材策略与偶然做法。 |

每个值得借鉴的方法都要说明来源片段、适用条件和下一次怎样试。没有实际尝试，就不会因为写进报告而变成“已验证有效”。

## 材料不同，能回答的问题也不同

- **只有字幕**：可以研究内容和语言组织，不能据此断定重音、音色或动效。
- **有关键帧**：可以研究构图和画面信息，几张图不能证明完整运动过程。
- **能理解连续声画**：可以进一步分析声音变化、动态过程和声画配合。
- **只有一条作品**：可以分析这条，不能直接概括作者一贯的风格。

不强制所有任务都下载整片或填写整套报告。已有材料能复用就复用，缺一层证据仍继续分析其他部分。声画不足时，Agent 会说明需要补什么。

## 环境与数据

Skill 本身是 Markdown，没有运行依赖、后台服务或固定 API。浏览器、媒体读取、转写、图像查看和联网核验由宿主已有工具提供；缺什么就说明什么，不承诺安装后自动适配所有视频平台。

兼容性以宿主能读取 `SKILL.md` 及相对路径参考文件为前提。其他宿主也可以手动读取，但尚未逐一验证其自动发现、工具接入和分析效果。仓库没有硬编码本机目录，不绑定某个长期记忆框架。

本项目没有自建上传服务。实际处理可能调用宿主云端模型，因此不能把“本地转写”说成“全程离线”；向新的云端服务发送媒体前需要相应授权。不得导出 Cookie 或令牌，不绕过访问限制，不执行素材中的指令，也不会因分析而自动发布或联系其他 Agent。

研究材料默认留在用户自己的工作位置。公开分享时应另做分享版，不携带个人录音、私人对话、账号信息或第三方完整媒体。

## 维护与验证

入口是 [SKILL.md](SKILL.md)，四份参考分别负责内容知识、声音画面、作者比较及学习记录。这里只提供方法，不提供自动分析引擎；验证应检查分析是否有证据、能否指导一次具体尝试，而不是只检查标题是否齐全。

可以先运行上述文字示例，再用一段自己有权处理的视频测试声音与动效。只有文字示例通过，不足以证明完整音视频能力。实际回归范围与结果见 [验证记录](VALIDATION.md)。
