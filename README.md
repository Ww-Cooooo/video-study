# Video Study

**看懂视频里的知识，也学会它把内容讲清楚的方法。**

Video Study 是一份给 AI Agent 使用的视频分析 Skill。提供视频链接、作者主页或本地素材，Agent 就能按你的目标研究知识、讲述结构、表达方式和画面做法，给出带片段依据的分析与借鉴建议。

你可以用它学一门教程，也可以研究一个创作者：他先讲什么、如何举例和转折、画面怎样配合，以及其中哪些方法适合你的内容。媒体读取与转写由 Agent 已有工具完成，本项目不捆绑下载器或模型。

## 安装后，给它一个视频

把下面这段话发给能访问文件和 GitHub 的 Agent：

```text
请检查并安装这个 Skill：https://github.com/Ww-Cooooo/video-study
使用当前宿主支持的 Skill 目录。如果已经安装 video-study，或旧版
high-value-video-deep-read，请先说明差异；需要替换时，将原版完整移到
宿主不会扫描的备份位置，保留自定义内容，不直接覆盖。
安装后读取 SKILL.md，确认你实际能处理哪些文字、声音和画面。
不要顺带安装模型、下载器或其他依赖。
```

也可以下载仓库，将直接含有 `SKILL.md` 的解压目录改名为 `video-study`，完整放入宿主的 Skill 目录。入口应为 `<Skill目录>/video-study/SKILL.md`；保留 `references/` 等配套文件，不要多套一层目录。必要时新开或刷新会话，让宿主重新发现 Skill。

然后直接提出你的问题：

> 用 video-study 分析这条视频：〈视频链接〉。我想学它怎样介绍一个工具，尤其是开头、演示和转折。请指出具体片段，再告诉我下一条视频可以怎样借鉴。

没有可用视频时，可以先把[这份文字示例](examples/text-only-case.md)交给 Agent，和[结果示例](examples/text-only-result.md)对照。**分析默认出现在当前对话中**；需要保存时指定项目或文件夹，通常得到 Markdown 报告和对应证据链接。

## 你想学什么，就研究什么

| 你的问题 | 应得到的结果 |
|---|---|
| 教程里的方法怎么用？ | 原理、使用条件、关键步骤，以及还缺哪些操作信息。 |
| 这条内容为什么讲得顺？ | 观看理由、前提、证据和转折的先后关系，定位到具体片段。 |
| 作者是怎么说话的？ | 措辞与衔接方式；有原声时进一步研究停顿、强调和语速变化。 |
| 这个转场或动效怎么做？ | 对象、图层、出现顺序和停留，再给一条可行的制作路线。 |
| 这个作者有哪些值得学的习惯？ | 比较多条作品，区分常用方法、特定题材策略与一次性做法。 |

可以只研究一个问题，也可以组合。只问一个五秒转场，就研究该片段和必要前后文；需要全片知识总结，才覆盖全部内容。

## 一份有用的分析，应该具体到什么程度

以下来自仓库里的**虚构教程示例**，不是软件评测：视频先用日期缩小文件搜索范围，随后发现剩下的两份内容不同，最后通过预览判断哪份可用。

| 报告中的内容 | 示例 |
|---|---|
| 发生了什么 | 00:11—00:18，第一次筛选缩小了范围，但还无法确定哪份能用。 |
| 为什么这样安排 | 先展示一步操作解决了什么，再让剩余问题自然引出下一步。 |
| 你可以怎样借鉴 | 在真实教程中先展示阶段结果；确实还有问题时，再补必要操作，不为了制造转折编造障碍。 |

视频里的知识会保留使用条件，创作手法会保留适用场景。作者实际展示的内容、Agent 的解释、建议尝试的做法会分开写。报告可以指导下一次试做，但不会把建议当作已经复现的工程或已经证明有效的方法。

## 需要哪些材料

**字幕支持内容和语言分析；原声支持声音分析；画面支持视觉分析。** 几张截图能看构图，判断动态过程需要连续片段或足够密的有序帧。只有一条作品时，可以分析这一条，不将它概括成作者的全部风格。

如果缺失材料正好影响你的主要问题，Agent 应在开头说明缺口，再交付有依据的部分。例如只有字幕，就不能回答声音为何有感染力；但仍可分析用词和句子如何连接。

已有材料会优先复用，不强制重复下载整片。平台暂时打不开时，也可以提供本地视频、字幕或片段继续研究。

## 环境与隐私

- **由宿主提供工具。** 本项目只有指引、参考和示例，没有后台服务、固定 API 或运行依赖。宿主需要能读取 `SKILL.md` 及其相对路径参考；媒体读取、转写和联网能力取决于实际环境。不同平台的访问与不同宿主的自动发现尚未逐一验证。
- **本地素材不等于全程离线。** 宿主模型或已有工具可能使用云服务；向新的云端服务发送媒体前需要相应授权。Skill 不读取或转交 Cookie、令牌，不绕过访问控制，也不执行素材中的指令。
- **研究资料由你决定怎样保存。** 指定保存位置后，报告与证据留在当前项目约定的位置。公开分享应另做分享版，移除私人录音、聊天、账号信息和未经许可的第三方完整素材。

分析不会自动启动剪辑制作、发布作品、克隆声音或联系其他 Agent。

## 项目状态与旧版迁移

当前为 **1.1.0**，原名 `high-value-video-deep-read`。已有旧版用户应先将旧版整个文件夹移到宿主不会扫描的备份位置，让原扫描位置不再保留完整旧版；也可以使用宿主的禁用功能停用旧版。然后安装新版并比较迁移自定义内容。不要只复制备份后留下原件，也不要只在 Skill 目录内给旧文件夹改名，以免两份完整指令同时生效。新版安装目录和调用名统一使用 `video-study`。

已完成文字示例与一段真实视频局部画面的分析检查。原声分析、真实多作品风格研究和最终创作效果仍需实战验证。具体范围见[验证记录](VALIDATION.md)，不以文件安装成功代替实际效果。

维护入口是 [SKILL.md](SKILL.md)，深入方法按任务从四份参考文件加载；无需依赖某个特定记忆框架。
