# 作者比较与方法迁移

## 主页研究：有理由地取样，不抓全部历史

先利用可见标题、日期和类型选择少量有差异的候选；代表性常态作品优先，再按问题补近期、不同题材/时长或不同表现的作品。记录选择理由与未覆盖类别，不能只取最热门一条，也不把无法比较曝光窗口的低播放量当失败。

对每条选中作品按约定范围建立完整内容认识；只在新增样本能解决实质疑点时继续，不凑固定数量。主页不可达时可用用户给的链接或本地材料。只有一条就研究这条，把作者层面的结论留待更多证据，不妨碍当前分析。

## 比较重复特征、变化与例外

| 维度 | 比较什么 |
| --- | --- |
| 内容选择 | 服务谁、回应什么问题、作出什么承诺。 |
| 结构 | 看点、前提、证据、转折与兑现的先后；不同题材是否换了组织方式。 |
| 语言与幽默 | 称呼和指向、衔接、解释、比喻、角色反应、回扣与口头词的实际作用。 |
| 声音 | 原声确实可理解且任务包含此项时，比较重音、停顿和情绪变化。 |
| 视觉与动态 | 版式、层级、信息展开、品牌符号与有依据的音画关系。 |
| 互动 | 请求观众做什么，怎样接住问题；公开反馈覆盖到哪里。 |

不要逐条各写一段形容词。重要结论区分**多作品重复特征、题材策略、单次做法、暂不能确定**，指回对应位置和已知例外；未取得例外材料如实说明，不造反例。团队制作、商业合作等归因不明时，不把所有安排都归于作者个人。

## 把原例变成当前可用的办法

先对照用户任务、受众、已有表达/品牌、材料与制作条件。已知信息不重问；没有具体项目时给适用场景，不替用户确定人设。

每项重要迁移说明：
1. 原例真正起作用的关系或动作是什么；
2. 当前哪处内容能用，具体保留、替换或删改什么；
3. 需要哪些真实事实/证据、有什么不适用条件；
4. 怎样观察这次应用有没有达到目的。

例如借鉴“同条件改前—改后比较”，应换成用户的真实输入与输出；不能借用作者的测试结果，也不能为了结构好看捏造一个失败。合理假设小样须说明是示意，不记录成本人经历。

按任务深度推进：只研究也应完成相关工具/方法的必要使用调查，给出具体用法，不能把“未要求制作”解释为“只许提建议，不查怎样用”。明确要求用于当前作品且材料足够，就交付相称的改写片段、画面设计或操作小样，并标出采用关系。别永远停在“以后可以试试”，也别把一次分析扩成未经请求的整篇脚本、工程、声音训练或发布。

按对象保留原例、解释和可复用产物之间的联系。文案可用原句与改稿对照，操作可用输入/步骤/输出，制作可在许可与授权允许时使用具体工程；一段抽象技巧总结不能证明迁移成功，也不能从一个案例推出“以后都应直接复刻”。实际用过与产生效果仍需对应证据。

按价值、适配性和执行代价决定本次先用什么，不设只能学一两项的固定配额；其他有用内容留作可查资料。完整新稿遵守用户已有交付与修订约定。台词、标志、专属视觉资产和声音身份不直接搬用；技术可行不等于用户采用或许可允许。

## 反馈同时检查分析与应用

用户指出遗漏，按主入口区分材料缺失、理解错误、取舍失误、未落实到应用；不要只追加一句“以后注意”。回到对应来源、原解释和实际产物，修正受影响部分，保留必要历史。若是表达偏好而非事实错误，按偏好调整应用，不倒写成原作者的问题。

一次应用不佳，不足以否定原方法，也不能都怪用户没照做；核对输入、受众、上下文、执行及解释差异。用户认可一句只证明该范围，真实观看/使用结果才支持相应效果结论，不用模型评分或多方赞同代替。

保存仍走既有任务入口，观察和试用反馈分开；当前材料和稳定经验的归属遵守项目授权。不会因研究成功自动改全局提示、建立新知识库或联系其他 Agent。必要交接只给目标、证据、实际改动与未解决问题，沿用原分工。
