# 输出与学习记录

用于需要保存或交接的深读；不是每次必填的表格。优先直接回答问题，没有材料的项目注明影响，不用空表拉长报告。

## 推荐内容

1. **结论**：最值得学什么，哪些不适合照搬，为什么。
2. **材料范围**：来源、日期、覆盖区间；正文/原声/静态帧/连续片段/评论/外部核验的真实状态。
3. **关键证据**：时间或段落、实际出现的信息/声画、解释及限制。短引文与自己的概述分清。
4. **知识或方法**：适用问题、条件、可采取动作；作者主张、核验事实和推断分清。
5. **下一次应用**：最值得试的改动、所需材料、最小验证；未实际尝试不称有效。

作者研究附样本选择与跨作品比较；动效研究附过程/实现卡；知识研究附重要主张与操作条件。无需同时塞入所有模式。

## 保存后的召回

使用已有项目目录和检索方式。报告可以承担完整证据，不必每项再生成一个文件。入口只存一句用途、能命中的日常说法和正文链接；保存后从入口实际打开一次。

例如触发说法“拆这个作者的转场”“学视频里的方法”“分析他说话的节奏”，比只登记一个内部编号更好找。共享 Skill 的正文不写某个用户的本地目录、账号名或私人偏好；这些放在该用户的项目里。

## 状态要能更新

- 观察到：有来源和片段依据。
- 建议试用：解释与适用条件明确，但尚未应用。
- 已实际采用：有具体作品/试做记录，不能推断效果已提升。
- 效果有证据：有相应观察、用户反馈或合理比较；写清能支持到哪一步。

用户纠正时更新原条目及受影响结论，保留必要来源，不靠追加相互冲突的规则解决。只有可重建索引失败时局部重试，不让报告或其他能力失效。
