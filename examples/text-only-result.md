# 示例结果：把一次操作拆成有来由的两步

这是对[虚构字幕示例](text-only-case.md)的分析节选，经编辑整理。不是对真实软件的评测，也不是原视频复刻。

最值得学的是：先解决一部分问题，再用剩下的问题解释为什么还需要下一步。日期让文件更好找，内容预览才帮助判断哪份能用。

| 位置 | 具体安排 | 为什么值得学 |
|---|---|---|
| 00:00—00:11 | 先说找收据遇到的问题，再给文件名加日期 | 观众知道为什么要做这一步。 |
| 00:11—00:18 | 搜索范围缩小，但两份内容不同 | 阶段结果确实帮了忙，同时交代它还解决不了什么。 |
| 00:18—00:33 | 预览后判断用途，再总结查找顺序 | 下一步有具体理由，结论也能回到刚才的例子。 |

可以迁移的做法：在一个真实教程里展示第一步的结果；确实还有问题时，再引出下一步。不要为了套这种结构编造障碍。

知识边界：示例没有交代日期的含义和具体搜索操作，因此不足以成为可照做的软件教程。文字中的“看这里”“这份”依赖画面指向，拍摄时要让观众看清对象。

当前仅分析了全部人工字幕。没有音频或画面，不能判断作者重音、停顿、转场效果或实际演示结果，也不能概括某位作者的固定风格。上述方法处于建议试用状态，尚未证明改善观看效果。
